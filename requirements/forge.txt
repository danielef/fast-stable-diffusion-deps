# ── Packages never bundled in the blob ────────────────────────────────────────
#
# torch/torchvision/torchaudio  (Colab: 2.11.0+cu130)
#   CUDA-coupled; Colab ships GPU builds; CPU PyPI builds would break GPU inference.
#   triton: version-coupled to torch; mismatched triton causes inductor errors.
#   nvidia-*: CUDA libraries pulled in as torch sub-deps; huge and GPU-specific.
#
# numpy  (Colab: 2.1.3)
#   C ABI is tightly coupled to Colab's exact Python+CUDA build. The blob's
#   pinned packages do not use the NumPy C ABI directly (pure-Python), so
#   Colab's numpy is always compatible. A prior 1.26.4 downgrade broke
#   Colab's JAX/TF (numpy.dtypes.StringDType requires NumPy 2.x), which are
#   loaded transitively by transformers 4.46.1 at startup. Permanently excluded.
#
# scikit-image  (Colab: 0.25.2)
#   No Python 3.13 wheels exist for any scikit-image release (checked through
#   0.9.3 on 2026-11-01). diffusers 0.31.0 imports skimage only in optional
#   pipeline modules (not at top-level import); Colab's 0.25.2 is compatible.
#   Re-evaluate when a py3.13 wheel appears on PyPI.
#
# tqdm, requests, psutil, lark  (Colab versions compatible)
#   Stable stdlib-adjacent utilities; APIs unchanged across recent versions.
#
# ── Packages the blob OVERWRITES (Colab ships incompatible newer versions) ────
#
#   gradio:       Colab 6.30.0 → blob 4.40.0  (Forge uses gradio 4.x API)
#   transformers: Colab 5.21.0 → blob 4.46.1  (Forge relies on 4.x API)
#   diffusers:    Colab 0.42.1 → blob 0.31.0
#   accelerate:   Colab 1.15.0 → blob 0.34.2  (v1 introduced breaking API changes
#                   for Forge; 0.34.2 is the last 0.x stable release; adds
#                   clear_device_cache natively (was in sitecustomize.py shim);
#                   explicitly supports numpy <3.0 so Colab's numpy 2.x is fine)
#   peft:         Colab newer  → blob 0.21.2  (pinned to prevent API drift with
#                   accelerate 0.34.2; Renovate will bump with CI gating)
#   protobuf:     Colab 6.33.6 → blob 3.20.0  (Forge hardcodes 3.x API; ships
#                   py3-none-any wheel)
#   Pillow:       Colab 11.3.0 → blob 10.4.0  (gradio 4.x requires pillow<11.0;
#                   blendmodes 2024 requires pillow>=10.0; 10.4.0 has py3.13 wheels)
#   huggingface-hub: Colab 1.33.0 → blob 0.26.0  (1.x removed HfFolder; gradio
#                   4.40.0 imports it; peft 0.21.2 requires >=0.25.0)
#   starlette:    Colab N/A → blob 1.3.1  (1.0.0 removed TemplateResponse(name, context)
#                   old-style API; build_blob.sh patches starlette/templating.py to
#                   restore backward-compat; fixes CVE-2024-47874, CVE-2025-62727,
#                   GHSA-82w8-qh3p-5jfq)
#   fastapi:      Colab N/A → blob 0.133.0  (first release dropping starlette<1.0.0
#                   upper bound; satisfies gradio 4.40.0's fastapi>=0.103.1)
#
# ── Packages pinned to prevent version drift (same or close to Colab) ─────────
#
#   httpx:        0.28.1  (gradio 4.40.0 requires >=0.24.1; pinned so Colab upgrades
#                   don't silently break gradio's HTTP client)
#   pydantic:     2.14.2  (gradio 4.40.0 requires >=2.0; pydantic v2 has had breaking
#                   changes between minor versions; pinned to prevent silent breakage)
#   pydantic_core: 2.50.2  (must match pydantic 2.14.2 exactly; auto-bumped with pydantic)
#   einops:       0.8.2   (used by open-clip-torch 2.20.0 at runtime; stable API)
#   safetensors:  0.8.0   (used by accelerate, diffusers, peft; stable API)
